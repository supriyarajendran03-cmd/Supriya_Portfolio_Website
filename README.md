# Supriya R — Personal Portfolio Website

A responsive portfolio website made with **HTML, CSS, and vanilla JavaScript**. No frameworks or backend are used.

## Files
- `index.html` — page content and sections
- `css/style.css` — layout, responsive styling, themes and project visuals
- `js/script.js` — mobile navigation, theme toggle, project filters, project details and contact-form validation

## Run locally
Open `index.html` in a browser. For final academic submission, publish the files to a public GitHub repository and deploy the site with GitHub Pages (or another host your trainer accepts).

## Before submitting
1. Review every paragraph and make sure it represents your own work and skills.
2. Add your actual GitHub repository and deployed project links if available.
3. Test the page on both phone and laptop.
4. Submit both the live URL and repository URL in the college Google Form.
5. Demonstrate the live site and source code to your trainer.

## Notes
- The three project cards are portfolio examples based on learning/practice work. Edit them to match projects you have actually built.
- The contact form is front-end only: it validates fields and displays a confirmation but does not send email.
- No personal phone number or home address is published.
